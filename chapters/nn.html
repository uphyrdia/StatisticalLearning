\section{Convolutional neural networks}

Throughout, \(c_\text{in}\in\NN\) is the \textit{input channel dimension} and \(c_\text{out}\in\NN\) the \textit{output channel dimension}. Points \(q\in\ZZ^2\) are called \textit{pixels}, and \((e_q)_{q\in\ZZ^2}\) is the standard basis of \(\RR^{\oplus\ZZ^2}\). An input is a tensor in \(\RR^{c_\text{in}}\otimes\RR^{\oplus\ZZ^2}\) and an output is a tensor in \(\RR^{c_\text{out}}\otimes\RR^{\oplus\ZZ^2}\).

\subsection{Images as modules}\label{sec-images-modules}

For \(c\in\NN\) let \(\mathcal{F}_c\) be the space of finitely supported functions \(\ZZ^2\to\RR^c\).

\begin{thm}\label{thm-images-functions}

The linear map \[ \RR^c\otimes\RR^{\oplus\ZZ^2}\longrightarrow\mathcal{F}_c,\qquad v\otimes e_q\longmapsto\bigl(q'\mapsto v\text{ if }q'=q,\ 0\text{ otherwise}\bigr) \] is an isomorphism. Its inverse sends \(y\) to \(\sum_{q\in\ZZ^2}y(q)\otimes e_q\).

\end{thm} \begin{proof}

Tensor products commute with direct sums, so \(\RR^c\otimes\RR^{\oplus\ZZ^2}=\RR^c\otimes\bigoplus_{q}\RR e_q\cong\bigoplus_{q}\RR^c\), and \(\bigoplus_q\RR^c\) is exactly \(\mathcal{F}_c\). The given map is this isomorphism.

\end{proof}

From now on, inputs and outputs are identified with elements of \(\mathcal{F}_{c_\text{in}}\) and \(\mathcal{F}_{c_\text{out}}\), and \(y(q)\) is the \textit{value} of \(y\) at the pixel \(q\). An input of \textit{width} \(w\in\NN\) and \textit{height} \(h\in\NN\) is an \(x\in\mathcal{F}_{c_\text{in}}\) supported in \(\{0,\dots,w-1\}\times\{0,\dots,h-1\}\).

For \(u\in\ZZ^2\), the \textit{shift} \(S_u\) acts on every \(\mathcal{F}_c\) by \[ (S_uy)(q)=y(q+u), \] i.e. \(S_u(v\otimes e_q)=v\otimes e_{q-u}\). These shifts satisfy \(S_uS_{u'}=S_{u+u'}\) and \(S_0=\mathrm{id}\). So \(\ZZ^2\) acts on \(\mathcal{F}_c\), which makes \(\mathcal{F}_c\) a module over the group algebra \[ A=\RR[\ZZ^2]=\RR[t_1^{\pm1},t_2^{\pm1}], \] the ring of Laurent polynomials, with \(t^m=t_1^{m_1}t_2^{m_2}\) acting as \(S_{-m}\). Explicitly, for \(a=\sum_m a_mt^m\in A\), \[ (a\cdot y)(q)=\sum_{m\in\ZZ^2}a_m\,y(q-m), \] so the module structure is convolution with scalar filters. Identifying \(e_q\) with \(t^q\) gives \(\RR^{\oplus\ZZ^2}=A\), and hence \(\mathcal{F}_c\cong\RR^c\otimes A\cong A^c\), a free \(A\)-module of rank \(c\) with basis \(\epsilon_\ell\otimes1\), where \((\epsilon_\ell)\) is the standard basis of \(\RR^c\).

A linear map \(K:\mathcal{F}_{c_\text{in}}\to\mathcal{F}_{c_\text{out}}\) commutes with all shifts if and only if it is \(A\)-linear, since \(A\) is spanned by the monomials \(t^m\), which act as shifts.

\subsection{Convolutional layers} \begin{def}\label{def-local-equivariant}

Let \(s\in\NN\) and let \(B\subset\ZZ^2\) be finite. A linear map \(K:\mathcal{F}_{c_\text{in}}\to\mathcal{F}_{c_\text{out}}\) is

  • \textit{\(s\)-equivariant} if \(K\circ S_{su}=S_u\circ K\) for all \(u\in\ZZ^2\): shifting the input by \(s\) pixels shifts the output by one pixel;
  • \textit{\(B\)-local} if \((Kx)(0)=0\) whenever \(x\) vanishes on \(B\): the output at the pixel \(0\) only sees the input on \(B\).

If \(K\) is \(s\)-equivariant and \(B\)-local, then \((Kx)(q)=\bigl(K(S_{sq}x)\bigr)(0)\), and \(S_{sq}x\) vanishes on \(B\) if and only if \(x\) vanishes on \(sq+B\). So the output at the pixel \(q\) only sees the input on the patch \(sq+B\).

\end{def} \begin{thm}\label{thm-equivariant-maps}

A linear map \(K:\mathcal{F}_{c_\text{in}}\to\mathcal{F}_{c_\text{out}}\) is \(s\)-equivariant if and only if there is a finitely supported family \((K_u)_{u\in\ZZ^2}\) of linear maps \(\RR^{c_\text{in}}\to\RR^{c_\text{out}}\) such that \[ (Kx)(q)=\sum_{u\in\ZZ^2}K_u\,x(sq+u)\qquad\forall x\in\mathcal{F}_{c_\text{in}},\ q\in\ZZ^2. \] The family is unique, namely \(K_uv=K(v\otimes e_u)(0)\). Moreover, \(K\) is \(B\)-local if and only if \(K_u=0\) for all \(u\notin B\).

In tensor notation, let \(T^s_u:\RR^{\oplus\ZZ^2}\to\RR^{\oplus\ZZ^2}\) send \(e_n\) to \(e_{(n-u)/s}\) if \((n-u)/s\in\ZZ^2\), and to \(0\) otherwise, so that \((T^s_uy)(q)=y(sq+u)\). Then the formula reads \[ K=\sum_{u\in\ZZ^2}K_u\otimes T^s_u . \]

\end{thm} \begin{proof}

\textit{If.} For \(x\in\mathcal{F}_{c_\text{in}}\) and \(q,u\in\ZZ^2\), \[ \bigl(KS_{su}x\bigr)(q)=\sum_mK_m\,x(sq+m+su)=\sum_mK_m\,x\bigl(s(q+u)+m\bigr) =(Kx)(q+u)=\bigl(S_uKx\bigr)(q). \]

\textit{Only if.} Put \(K_uv=K(v\otimes e_u)(0)\). For \(n,q\in\ZZ^2\) we have \(v\otimes e_n=S_{-sq}(v\otimes e_{n-sq})\), so \(s\)-equivariance gives \[ K(v\otimes e_n)(q)=\bigl(S_{-q}K(v\otimes e_{n-sq})\bigr)(q)=K(v\otimes e_{n-sq})(0) =K_{n-sq}\,v . \] This is the claimed formula for \(x=v\otimes e_n\), since the right side then has the single term \(u=n-sq\). Both sides are linear in \(x\), so the formula holds for all \(x\).

\textit{Finite support.} Write \(u=r+sm\) with \(r\in\{0,\dots,s-1\}^2\) and \(m\in\ZZ^2\). Then \(K(v\otimes e_u)=S_{-m}K(v\otimes e_r)\), so \(K_uv=K(v\otimes e_r)(-m)\). For each of the \(s^2\) residues \(r\) and each basis vector \(v\), the output \(K(v\otimes e_r)\) has finite support, so only finitely many \(K_u\) are nonzero.

\textit{Uniqueness.} Put \(x=v\otimes e_u\) and \(q=0\) in the formula: \((Kx)(0)=K_uv\).

\textit{Locality.} By the formula, \((Kx)(0)=\sum_uK_u\,x(u)\). If \(K_u=0\) for \(u\notin B\), this vanishes whenever \(x\) vanishes on \(B\). Conversely, if \(u\notin B\), then \(x=v\otimes e_u\) vanishes on \(B\), so \(B\)-locality gives \(0=(Kx)(0)=K_uv\) for all \(v\).

\end{proof}

In module language. For \(s=1\), the theorem is the familiar fact that a homomorphism of free modules is a matrix over the ring: \[ \mathrm{Hom}_A\bigl(A^{c_\text{in}},A^{c_\text{out}}\bigr)\cong M_{c_\text{out}\times c_\text{in}}(A), \qquad K\longmapsto\sum_{u}K_u\,t^{-u}, \] determined by the images of the basis vectors \(\epsilon_\ell\otimes1\). Composing stride-\(1\) maps multiplies these polynomial matrices, and the support of \((K_u)\) is the set of exponents that occur, up to sign. For general \(s\), let \(A_s=\RR[t_1^{\pm s},t_2^{\pm s}]\) and \(\varphi:A_s\to A\), \(t^{sm}\mapsto t^m\). Then \(s\)-equivariance says \(K(ax)=\varphi(a)K(x)\) for \(a\in A_s\), i.e. \(K\) is \(\varphi\)-semilinear. Over \(A_s\), the module \(A\) is free with basis \(t^r\), \(r\in\{0,\dots,s-1\}^2\), which is why the residues \(r\) appear in the finiteness argument.

\begin{def}\label{def-convolution}

Let \(k,s\in\NN\) and \(p\in\NN\cup\{0\}\) with \(w+2p\geqslant k\) and \(h+2p\geqslant k\). Put \(w'=\lfloor (w+2p-k)/s\rfloor\), \(h'=\lfloor (h+2p-k)/s\rfloor\), \[ B=\{-p,\dots,k-1-p\}^2,\qquad\Omega=\{0,\dots,w'\}\times\{0,\dots,h'\}. \] A 2D \textit{convolutional layer} of \textit{size} \(k\), \textit{stride} \(s\), with \textit{padding} \(p\), is a map \(f:\mathcal{F}_{c_\text{in}}\to\mathcal{F}_{c_\text{out}}\) of the form \[ f(x)(q)= \begin{cases} b+(Kx)(q) & \text{if }q\in\Omega\\ 0 & \text{otherwise} \end{cases} \] where \(K\) is an \(s\)-equivariant, \(B\)-local linear map and \(b\in\RR^{c_\text{out}}\) is a learnable vector called the \textit{bias}. The family \(W_{i,j}=K_{(i-p,j-p)}\), \(i,j\in\{0,\dots,k-1\}\), of learnable linear maps \(\RR^{c_\text{in}}\to\RR^{c_\text{out}}\) is called the \textit{kernel}, and \(\Omega\) the \textit{output window}. The output has width \(w'+1\) and height \(h'+1\).

\end{def} \begin{thm}\label{thm-pixelwise}

A convolutional layer is given pixelwise by \[ f(x)(q)=b+\sum_{i,j=0}^{k-1}W_{i,j}\,x\bigl(sq+(i-p,\,j-p)\bigr)\qquad\forall q\in\Omega, \] i.e. its linear part is \(\sum_{i,j=0}^{k-1}W_{i,j}\otimes T^s_{i-p,j-p}\), writing \(T^s_{i,j}=T^s_{(i,j)}\). Moreover, \(\Omega\) is exactly the set of pixels \(q\in\ZZ^2\) whose patch \(sq+B\) lies inside the padded input \(\{-p,\dots,w-1+p\}\times\{-p,\dots,h-1+p\}\).

\end{thm} \begin{proof}

The formula is , with \(K_u=0\) for \(u\notin B\) by locality and \(u=(i-p,j-p)\) running over \(B\). For the window, the patch \(sq+B\) has first coordinates \(sq_1-p,\dots,sq_1+k-1-p\). These lie in \(\{-p,\dots,w-1+p\}\) if and only if \(sq_1-p\geqslant-p\) and \(sq_1+k-1-p\leqslant w-1+p\), i.e. \(0\leqslant q_1\leqslant(w+2p-k)/s\), i.e. \(0\leqslant q_1\leqslant w'\). The same holds for the second coordinate.

\end{proof} \subsection{Why parameters are shared across pixels}\label{sec-shared-parameters}

Shifts never commute with a layer that has a nonzero bias, since the output is supported on the finite output window. The right notion is therefore equivariance away from the edges of the window. For simplicity, take stride \(1\) in this subsection.

\begin{def}\label{def-equivariant-on}

Let \(\Omega\subset\ZZ^2\). A map \(f\) from inputs to outputs is \textit{equivariant on} \(\Omega\) if, for all inputs \(x\) and all \(u\in\ZZ^2\), \[ f(S_ux)(q)=\bigl(S_uf(x)\bigr)(q)\qquad\text{whenever }q\in\Omega\text{ and }q+u\in\Omega. \] That is, shifting the input shifts the output, except at pixels shifted into or out of \(\Omega\). The same definition applies to maps from outputs to outputs.

\end{def} \begin{thm}\label{thm-shared-bias}

Let \(\Omega\subset\ZZ^2\), let \(K:\mathcal{F}_{c_\text{in}}\to\mathcal{F}_{c_\text{out}}\) be \(1\)-equivariant, and let \(b_q\in\RR^{c_\text{out}}\) for \(q\in\Omega\). The map \(f\) with \(f(x)(q)=b_q+(Kx)(q)\) for \(q\in\Omega\), and \(f(x)(q)=0\) otherwise, is equivariant on \(\Omega\) if and only if \(b_q\) does not depend on \(q\).

In particular, a convolutional layer () with stride \(1\) and any padding is equivariant on its output window. A bias that varied from pixel to pixel would break this.

\end{thm} \begin{proof}

Let \(q,q+u\in\Omega\). Since \(K\) commutes with \(S_u\), \[ \begin{aligned} f(S_ux)(q)&=b_q+(S_uKx)(q)=b_q+(Kx)(q+u),\\ \bigl(S_uf(x)\bigr)(q)&=f(x)(q+u)=b_{q+u}+(Kx)(q+u). \end{aligned} \] So \(f\) is equivariant on \(\Omega\) if and only if \(b_q=b_{q+u}\) whenever \(q,q+u\in\Omega\). Any two pixels \(q,q'\in\Omega\) are related by the shift \(u=q'-q\), so this says exactly that \(b_q\) is constant on \(\Omega\).

\end{proof}

At inference, batch normalisation acts on the value of an output \(y\) at each pixel by an affine map. Allowing separate parameters at each pixel \(q\in\Omega\), it is the map \(g\) with \[ g(y)(q)=D_q\,y(q)+\beta'_q\quad(q\in\Omega), \qquad D_q=\mathrm{diag}\Bigl(\frac{\gamma_\ell}{\sigma_{\ell,q}}\Bigr)_{\ell}, \quad \beta'_q=\Bigl(\beta_\ell-\frac{\gamma_\ell\,\mu_{\ell,q}}{\sigma_{\ell,q}}\Bigr)_{\ell}, \] and \(g(y)(q)=0\) for \(q\notin\Omega\). Here \(\ell\) runs over the channels, \(\mu_{\ell,q}\) and \(\sigma_{\ell,q}^2\) are the mean and variance used for channel \(\ell\) at pixel \(q\), and \(\gamma_\ell,\beta_\ell\) are the learnable scale and shift.

\begin{thm}\label{thm-batch-norm}

Let \(\Omega\subset\ZZ^2\), and for \(q\in\Omega\) let \(D_q:\RR^{c}\to\RR^{c}\) be linear and \(\beta'_q\in\RR^{c}\). Let \(g(y)(q)=D_q\,y(q)+\beta'_q\) for \(q\in\Omega\), and \(g(y)(q)=0\) otherwise.

  1. \(g\) is equivariant on \(\Omega\) if and only if \(D_q\) and \(\beta'_q\) do not depend on \(q\).
  2. In that case, \(g\circ f\) is equivariant on \(\Omega\) for every map \(f\) that is equivariant on \(\Omega\).

In particular, take batch normalisation with \(\gamma_\ell\neq0\). Then \(g\circ f\) is equivariant on \(\Omega\) for every \(f\) equivariant on \(\Omega\), such as a convolutional layer of stride \(1\) with output window \(\Omega\), if and only if \(\mu_{\ell,q}\) and \(\sigma_{\ell,q}\) do not depend on \(q\). That is, there is one mean and one variance per channel, shared by all pixels.

\end{thm} \begin{proof}

\textit{Part 1.} Let \(q,q+u\in\Omega\). Then \[ \begin{aligned} g(S_uy)(q)&=D_q\,(S_uy)(q)+\beta'_q=D_q\,y(q+u)+\beta'_q,\\ \bigl(S_ug(y)\bigr)(q)&=g(y)(q+u)=D_{q+u}\,y(q+u)+\beta'_{q+u}. \end{aligned} \] If \(D_q\) and \(\beta'_q\) are constant, the two sides agree. Conversely, taking \(y=0\) gives \(\beta'_q=\beta'_{q+u}\). Taking \(y=v\otimes e_{q+u}\) then gives \(D_qv=D_{q+u}v\) for all \(v\in\RR^c\). As in the proof of , any two pixels of \(\Omega\) are related by a shift, so \(D_q\) and \(\beta'_q\) are constant on \(\Omega\).

\textit{Part 2.} Write \(D\) and \(\beta'\) for the constant values. Let \(q,q+u\in\Omega\). Since \(f\) is equivariant on \(\Omega\), \[ g\bigl(f(S_ux)\bigr)(q)=D\,f(S_ux)(q)+\beta'=D\,f(x)(q+u)+\beta'=g\bigl(f(x)\bigr)(q+u) =\bigl(S_u\,g(f(x))\bigr)(q). \]

\textit{In particular.} If \(\mu_{\ell,q}\) and \(\sigma_{\ell,q}\) are constant, then so are \(D_q\) and \(\beta'_q\), and part 2 applies. For the \textit{only if} direction, take \(f=\mathrm{id}\), which is equivariant on every \(\Omega\). Then \(g\circ f=g\) is equivariant on \(\Omega\), so by part 1, \(D_q\) and \(\beta'_q\) are constant. Since \(\gamma_\ell\neq0\), \(D_q\) constant means \(\sigma_{\ell,q}\) is constant, and then \(\beta'_q\) constant means \(\mu_{\ell,q}\) is constant.

\end{proof}

Estimating the statistics. The theorem says only that the mean and variance must be shared across pixels. It does not say how to estimate them. Pooling over the batch and all pixels is a good estimate when the data are roughly stationary, i.e. feature \(\ell\) has about the same distribution at every pixel. Then all \(N\cdot\lvert\Omega\rvert\) values of channel \(\ell\) in a batch of size \(N\) are samples of the same quantity.
