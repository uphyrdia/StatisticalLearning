Latin Modern Roman, version 2.005

This folder contains four unmodified OpenType files from the Latin Modern family:
lmroman10-regular.otf
lmroman10-bold.otf
lmroman10-italic.otf
lmroman10-bolditalic.otf

Each OpenType file also has a WOFF2 counterpart for smaller browser downloads.
The original OpenType files remain available as fallbacks and source files.

Authors: Boguslaw Jackowski and Janusz M. Nowacki, on behalf of TeX Users Groups.
Based on Donald E. Knuth's Computer Modern design.
Source: https://ctan.org/tex-archive/fonts/lm
Project: https://www.gust.org.pl/projects/e-foundry/latin-modern

Copied from the system fonts-lmodern distribution. The complete upstream family
and its other optical sizes are available at the source above. This template
uses the 10-point design at all CSS sizes; it does not reproduce TeX's automatic
selection of optical sizes.

WOFF2 copies were generated using FontTools 4.67.0 with Brotli 1.2.0, without
subsetting or glyph modification. All 821 glyphs, character mappings, outlines,
and metrics in each font are preserved. Validation compared every decoded font
table with its OpenType source; only the WOFF2 compression flag and font checksum
adjustment differ. The four browser fonts total 196,576 bytes, compared with
459,808 bytes for the original OpenType files (57.2% smaller).

See GUST-FONT-LICENSE.txt, COPYRIGHT.txt, and README-Latin-Modern.TXT for the
license, copyright notices, and upstream description. The WOFF2 files are
compressed copies of the bundled originals, not new font designs.
